# Lot de capturi native — runda 1 (vezi docs/parity-report/INDEX.md)
#
# Formatul unui pas:
#   capture:<ecran>/<stare>   screencap + uiautomator dump (focus verificat, antet PNG verificat)
#   tap:<etichetă>            dump -> nodul cu eticheta (sau textul) -> tap în centru
#   key:<nume>                `input keyevent` (ex. key:back ȋnchide orice Modal rămas deschis)
#   tapxy:<x>,<y>             tap la coordonate CSS px (măsurate din web-ref), când nodul nu are etichetă
#   wait:<ms>
#
# Rulare:  powershell -NoProfile -File tools/parity/device-batch.ps1 -List docs/parity-report/batch.txt
# Sesiunea cere: telefonul deblocat, Nexus Dev în prim-plan (app.nexus.mobile.dev), Wireless debugging pornit.
# Fiecare pas se sare dacă mCurrentFocus nu este app.nexus.mobile.dev.

# --- 0. reguli de sesiune (cerute de operator)
#   - NU se atinge cortina de notificări, NU se trimite Home sau Back;
#   - din aplicație se iese doar prin controalele ei („Închide", „Înapoi la conversații");
#   - dacă mCurrentFocus nu e app.nexus.mobile.dev, lotul face O SINGURĂ `am start -n …/.MainActivity`;
#     dacă tot nu e în prim-plan, se oprește și raportează, fără să trimită input.
